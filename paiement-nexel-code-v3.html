Sous le capot : l'API fait le travail

Pas de liens copiés-collés : notre page parle directement à l'API de paiement. Voici, en vrai, l'appel qui ouvre un paiement Équipe pour 10 développeurs.

// Créer le paiement — offre Équipe, 10 développeurs
const session = await stripe.checkout.sessions.create({
  mode: 'subscription',
  line_items: [{
    price: 'PRIX_EQUIPE_PAR_DEVELOPPEUR',  // 18 $ US
    quantity: 10                          // ← le nombre de développeurs
  }],
  success_url: 'https://nexel.example/merci'
});
// → total : 10 × 18 $ = 180 $ US / mois · paiement sécurisé par Stripe
